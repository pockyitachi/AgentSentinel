# Motivation study

This top-level directory contains the canonical Epic 1 research deliverables, separate from the
MobileWorld implementation tree:

- [`misleading_history_audit_report.md`](misleading_history_audit_report.md) is the final
  six-model observational report.
- [`epic1_failure_link_audit_v1/`](epic1_failure_link_audit_v1/) is the safe,
  machine-readable publication of aggregate results, frozen schemas, provenance hashes, and
  publication boundaries.

The implementation, validation code, and report renderer remain under `MobileWorld/`. Raw
requests, trajectories, reviewer text, screenshots, and the screenshot-embedding PDF remain
outside Git under the repository's data-governance rules.
